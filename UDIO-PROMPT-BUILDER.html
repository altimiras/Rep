📖 Notas sobre cómo funciona Udio

Formato del prompt: a diferencia de otros generadores que usan etiquetas entre corchetes para el estilo, Udio interpreta el campo de Tags como una lista de descriptores en lenguaje natural separados por comas. No hace falta sintaxis especial: mientras más específica y concreta sea cada frase (género + instrumentos + mood + producción), mejor interpreta el modelo la intención.

Modo Custom: Udio separa el título, el estilo (Tags) y la letra en campos distintos. La letra sí admite etiquetas de estructura como [Verse] y [Chorus] — pero eso corresponde al campo de Lyrics, no al que arma esta herramienta.

Extensión de pistas: si el resultado te gusta pero es corto, Udio permite extender la pista en incrementos manteniendo el mismo contexto musical (tono, tempo, estilo).

Consejo: si un prompt muy cargado de adjetivos da resultados dispersos, prueba recortar a los 4-6 descriptores más importantes (género, instrumento clave, mood, producción) — el resto se puede ajustar extendiendo o regenerando.
